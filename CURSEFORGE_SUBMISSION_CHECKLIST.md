# CurseForge Submission Checklist

## Project fields

- Project name: `AE2 Lightning Tech - Unofficial Forge 1.20.1 Port`
- Summary: `An independent Forge 1.20.1 port of AE2 Lightning Tech, with lightning power, advanced machines, and overloaded AE2 network components.`
- Main category: `Technology`
- Mod loader: `Forge`
- Game version: `Minecraft 1.20.1`
- Environment: `Client and server`
- License: `GNU Lesser General Public License version 3`
- Source: `https://github.com/syarukasu/AE2-Lightning-Tech-Forge-1.20.1`
- Issues: `https://github.com/syarukasu/AE2-Lightning-Tech-Forge-1.20.1/issues`

Use the complete contents of `CURSEFORGE_DESCRIPTION.md` as the English project
description.

## File fields

- Release type: `Release`
- Supported game version: `1.20.1`
- Supported loader: `Forge`
- Required dependency: `Applied Energistics 2`
- Changelog: contents of `CURSEFORGE_CHANGELOG_R8.md`
- Upload only: `ae2lt-1.1.4-forge-1.20.1-r8.jar`
- Do not upload the `-slim.jar` development artifact.

## Attribution review

- The description identifies the project as unofficial in its first paragraph.
- The original project, original authors, port maintainer, and support boundary
  are named explicitly.
- Upstream CurseForge and Modrinth links are labelled as the original NeoForge
  release rather than as download links for this port.
- `LICENSE`, `LICENSE_ASSETS.md`, `CREDITS.md`, and `PORT_NOTES.md` are included
  in both the repository and the distributable JAR.

## Resubmission

If the project status is `Changes Required`, update the existing project and
submit r8. If the project status is `Rejected`, create a new project with the
unique project name above; rejected projects cannot be re-evaluated.
