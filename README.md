# Repository moved

> [!IMPORTANT]
> This repository is a retired duplicate of the unofficial AE2 Lightning Tech
> Forge 1.20.1 port. Do not open new issues, pull requests, or releases here.

The single canonical Forge project is now:

```text
Repository   https://github.com/syarukasu/AE2-Lightning-Tech
Branch       forge-1.20.1-port
Issues       https://github.com/syarukasu/AE2-Lightning-Tech/issues
Releases     https://github.com/syarukasu/AE2-Lightning-Tech/releases
```

Use the canonical repository for:

- Forge 1.20.1 source and development;
- bug reports and feature requests;
- release downloads;
- the upstream AE2LT 2.0.6 backport roadmap;
- CurseForge/Modrinth distribution metadata;
- build, license, attribution, and port documentation.

This repository remains available only to preserve historical commits and links.
Its useful r8 packaging and distribution changes are being migrated into the
canonical `forge-1.20.1-port` branch before this repository is archived.
